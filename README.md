# Modern Coast Ltd website
Static site for GitHub Pages. Upload all files to a repo, then Settings > Pages > Deploy from branch (main, / root).
Custom domain: moderncoastltd.co.ke (CNAME file included). Point DNS A records to 185.199.108.153, .109.153, .110.153, .111.153 and add a CNAME for www -> USERNAME.github.io.
Edit fares in the R array near the bottom of index.html.
